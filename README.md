# Celeste RL Agent

A reinforcement learning (RL) agent designed to play **Celeste**, a high-precision platformer, using Deep Q-Learning techniques. This project explores the feasibility of training an RL agent to navigate challenging levels with sparse rewards, rapid failure states, and complex movement mechanics.

## Demo

A live demo of the agent in action can be found here:  
**[Demo Link](https://youtu.be/VsT70mcn2_0)**

## Features

- **Dueling Deep Q-Network (DQN)** for improved value estimation.  
- Integration with **Celeste** via a custom Gym environment.  
- Supports agent training and evaluation with **PyTorch**.  
- Visualization of training metrics such as reward progression and loss.  
- Easily configurable hyperparameters for experimentation.
